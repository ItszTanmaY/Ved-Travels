# Ved Travels Vadodara — Google Sheets Database & Offline Setup Guide

This guide explains how to connect **Google Sheets as your 100% FREE cloud database** for Ved Travels. With this setup, every customer reservation, offline UPI UTR payment, 4-digit handover OTP, and host vehicle submission will automatically write to a live Google Spreadsheet on your Google account—**zero monthly hosting bills, zero complex database servers**.

---

## 🚀 Quick Setup (Takes 2 Minutes)

### Step 1: Create a Google Sheet
1. Open [Google Sheets (sheets.new)](https://sheets.new) in your browser.
2. Name your spreadsheet: **`Ved Travels Fleet & Bookings Database`**.
3. (You do not need to create columns manually—the script will automatically create formatted tabs for **"Bookings"** and **"Vehicles"** with emerald and slate headers on the first request).

---

### Step 2: Open Google Apps Script
1. In the Google Sheets top menu bar, click:
   **Extensions** > **Apps Script**.
2. A new tab will open with a code editor named `Code.gs`.
3. Select and delete any default sample code in the editor.

---

### Step 3: Paste the Ved Travels Backend Script
1. Open the file [`google-apps-script.js`](file:///f:/VED-TRAVELS/google-apps-script.js) from the project root.
2. Copy all of the code and paste it into the Apps Script editor.
3. Click the **Save (Disk icon)** or press `Ctrl + S`.

---

### Step 4: Deploy as a Public Web App
1. At the top-right of the Apps Script page, click the blue **Deploy** button > **New deployment**.
2. Next to *Select type*, click the **Gear (⚙️) icon** and select **Web app**.
3. Fill in the deployment details:
   - **Description**: `Ved Travels Production API`
   - **Execute as**: `Me (your email address)`
   - **Who has access**: `Anyone` *(Crucial: Allows your Next.js website to post bookings securely)*
4. Click **Deploy**.

---

### Step 5: Authorize Permissions
1. Google will display a popup: *"Authorization required"*. Click **Review permissions**.
2. Select your Google account.
3. If Google shows a warning: *"Google hasn't verified this app"*, click **Advanced** at the bottom left, then click **Go to Untitled project (unsafe)**.
4. Click **Allow**.

---

### Step 6: Copy Web App URL & Add to Website
1. Copy the **Web app URL** generated by Google (it will look like: `https://script.google.com/macros/s/AKfycb.../exec`).
2. In your Ved Travels project root, open or create `.env.local` and add:

```env
NEXT_PUBLIC_GOOGLE_SHEETS_API_URL="https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec"
```

3. If you deploy on **Vercel** or **Netlify**:
   - Go to your Project Settings > **Environment Variables**.
   - Add Key: `NEXT_PUBLIC_GOOGLE_SHEETS_API_URL`
   - Add Value: `https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec`
   - Redeploy or trigger a build.

## 📊 How the Database Works

### 1. `Bookings` Spreadsheet Tab
Every time a customer books a bike or car, a new row is appended with:
- **Timestamp** (Date & Time of booking)
- **Booking Code** (e.g. `VED-BK-8421`)
- **Status** (`pending_offline_verification` / `confirmed_pay_at_hub` / `confirmed` / `in_trip`)
- **Vehicle Name & GJ-06 Plate**
- **Renter Name & Mobile Number**
- **Rental Duration & Dates**
- **Financial Breakdown** (Base Rent, Security Deposit, Delivery Fee, Total)
- **Payment Mode** (`upi_advance` or `pay_at_hub`)
- **UPI UTR / Reference Number** (Entered by customer during checkout)
- **4-Digit Start OTP** (Used by hub operator during machine key release)
- **Doorstep Delivery & Address** (if selected)

### 2. `Vehicles` Spreadsheet Tab
Every time a host submits a new bike or car via the Host Panel:
- Appends: Name, GJ-06 Plate, Category, Transmission, Fuel, Hourly Rate, Daily Rate, Security Deposit, Host Name, and Approval Status.
- Status is initially `pending_approval`.
- When the Admin approves the vehicle from the Admin Desk, the spreadsheet updates to `approved`.

## 💳 Offline Payments & WhatsApp Workflow

Ved Travels operates on a 100% free, transparent offline payment model:

1. **Option A — UPI Advance Payment**:
   - Customer scans the dynamic QR code for **`9546883777@upi`** (Ved Travels Vadodara) or pays via PhonePe/GPay/Paytm.
   - Customer enters their 12-digit UPI UTR / Transaction ID.
   - Status is set to `pending_offline_verification`.
   - Admin verifies the UTR in the **Admin Desk** or via WhatsApp message and clicks **"Verify UPI & Release OTP"**.

2. **Option B — Pay Entire Amount at Vadodara Hub**:
   - ₹0 online advance required.
   - Customer arrives at **Sayajigunj Central Hub (Platform 1 / RC Dutt Road)**.
   - Hub staff collects rent + refundable deposit in Cash or UPI.
   - Hub staff verifies customer's 4-digit OTP in the **Handover OTP** console and hands over the keys.

3. **WhatsApp Confirmation**:
   - Upon completing the reservation, a one-click **"Send Booking to Ved Travels WhatsApp"** button opens WhatsApp (`+91 95468 83777`) with the vehicle name, pickup time, pricing, and the 4-digit Start OTP pre-formatted.

## 🛡️ Offline Resilience
Even if the Google Sheets API URL is not set or Google experiences a brief downtime:
- All bookings and listings persist locally in the browser's `localStorage`.
- The user flow will never crash or hang.
- Once connected, sync resumes instantly in the background.
